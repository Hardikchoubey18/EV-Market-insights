EV Market Insights

An Electric Vehicle Market Analysis project combining Tableau dashboards, a Tableau Story, and a Flask web application.

Project Overview

This project explores electric vehicle market trends through interactive visualizations and data-driven insights.

Features

- EV market analysis using Tableau dashboards
- Market trends and performance insights
- Flask web application
- HTML frontend using Flask templates

Technologies Used

- Python
- Flask
- HTML
- Tableau
- Git and GitHub

Run Locally

1. Clone this repository:
   git clone https://github.com/Hardikchoubey18/EV-Market-insights.git
2. Open the project folder.
3. Install Flask:
   pip install flask
4. Run the application:
   python app.py
5. Open the local URL shown in your terminal.
